# Privacy Policy

**Last updated: July 2026**

## 1. Information We Collect

### 1.1 On-Chain Data (Public)
- Stellar wallet addresses
- Pool creation and funding activity
- Vote and dispute participation
- Smart contract interactions

All on-chain data is public by design and cannot be deleted.

### 1.2 Off-Chain Data (Optional)
- Email address (for notifications)
- Social media handles (for creator verification)
- IP address (for rate limiting and anti-fraud)
- Browser analytics (anonymized page views)

## 2. How We Use Data

- **On-chain data**: Displayed on the Platform, indexed by the API.
- **Email**: Transactional notifications (deposit confirmations, vote deadlines, dispute updates).
- **Social handles**: Creator verification badge display.
- **Analytics**: Platform improvement, fraud detection.
- **IP address**: Rate limiting, abuse prevention.

## 3. Data Storage

- On-chain data: Stored permanently on the Stellar network.
- Off-chain data: Stored in encrypted databases. Retention: 90 days after account inactivity.

## 4. Data Sharing

We do not sell your data. We may share with:
- **Service providers**: Hosting, email delivery, analytics (GDPR-compliant processors).
- **Legal authorities**: When required by law.

## 5. Your Rights (GDPR/CCPA)

- **Access**: Request a copy of your off-chain data.
- **Deletion**: Request deletion of off-chain data (on-chain data cannot be deleted).
- **Opt-out**: Disable analytics telemetry via `kindlepool-telemetry` localStorage flag set to `'false'`.
- **Data portability**: Export your data via the API.

To exercise rights: privacy@kindlepool.dev

## 6. Cookies

We use essential cookies for authentication. No tracking cookies. Analytics use anonymized, cookie-less tracking.

## 7. Security

- Smart contracts are publicly audited.
- Off-chain data is encrypted at rest and in transit.
- API keys are hashed before storage.

## 8. Changes

Material changes will be announced via the Platform and email (if subscribed).
